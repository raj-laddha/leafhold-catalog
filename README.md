<h1 align="center">Leafhold Catalog</h1>

<p align="center">
  <strong>The list of AI models that Leafhold Library offers.</strong>
</p>

---

This repository holds the model list that [Leafhold Library](https://github.com/raj-laddha/leafhold-library-releases) shows under **Settings → Models**. You do not need anything from here to use the app.

- **Why it is here:** the list is published with GitHub Pages, so a model can be added or a description fixed without a new version of the app.
- **It is signed:** the app only uses a list whose signature checks out, and it always has a built-in list to fall back on, so it works offline too.
- **Models are not stored here:** each model is made by another company and has its own licence, linked in the list and shown in the app.
